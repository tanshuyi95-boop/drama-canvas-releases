# Tree Canvas

Windows 桌面画布，可连接你自己部署的 ComfyUI。

**[下载最新版安装包](https://github.com/tanshuyi95-boop/drama-canvas-releases/releases/latest)**

打开下载页面，在 Assets 中选择 `TreeCanvas-Setup-...-Windows-x64.exe`，运行安装后从桌面“Tree Canvas”打开。首次使用填写自己的 ComfyUI 地址，导入自己的 API 工作流。

软件启动时检查更新，也可在“设置 → 软件更新”中检查。发现新版后点击更新，安装后重新打开，保留原有项目、素材、工作流和设置。

本仓库只发布安装包和更新文件，不包含用户项目、素材、工作流、源码或密钥。`.blockmap` 与 `latest.yml` 供软件更新使用；朋友无需手动下载。此处的 Source code 压缩文件只有发布仓库说明，不是安装程序。
